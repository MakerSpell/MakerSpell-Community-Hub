# 🌐 MakerSpell Web Platform Overview

The MakerSpell Web Platform ([makerspell.com](https://www.makerspell.com)) connects 26 major 3D model repositories into a single search engine, curates deals on hardware and filament, and monitors global design contests.

![MakerSpell Web Platform](../../assets/screenshots/web/sample-web.png)

---

## 🌟 Core Platform Modules

1. **🔎 Federated 3D Search (`/browse`):**
   Search millions of STL/3MF models across Printables, Thingiverse, MakerWorld, Cults3D, Thangs, and 20+ other platforms in one unified search bar.
2. **🏷️ 3D Deals & Coupons (`/deals`):**
   Daily verified discounts, coupon codes, and special promotions for 3D printers, filaments, and parts.
3. **🏆 Global Design Contests (`/contests`):**
   Live tracking of 3D modeling competitions, prize pools, submission criteria, and deadlines across all major platforms.
4. **👑 Membership & Founder's Pass (`/pricing`):**
   Ad-free browsing, priority slicing compute, and unlimited farm management plans.
